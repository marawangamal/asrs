### Name
Injective (one-to-one)
### Question
What does it mean for a function to be injective?
### Answer
A function $f : A \to B$ is **injective** (one-to-one) if distinct inputs map to distinct outputs:
$$
f(x_1) = f(x_2) \implies x_1 = x_2.
$$

Equivalently, $x_1 \neq x_2 \implies f(x_1) \neq f(x_2)$. For linear maps between vector spaces this is the same as saying the kernel is trivial: $\ker f = \{0\}$.
