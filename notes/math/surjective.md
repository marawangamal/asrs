### Name
Surjective (onto)
### Question
What does it mean for a function to be surjective?
### Answer
A function $f : A \to B$ is **surjective** (onto) if every element of the codomain is hit:
$$
\forall y \in B,\ \exists x \in A \text{ such that } f(x) = y.
$$

Equivalently, the image equals the codomain: $f(A) = B$. Contrast with injective (one-to-one); a function is **bijective** iff both.
